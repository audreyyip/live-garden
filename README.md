# Carrot Go
Pokemon Go + Animal Crossing prototype. No backend, no saved data (resets on reload).

    npm install
    npm run dev        # open on phone via the Network url (shake needs https, so test shake on github pages)

Deploy: push to `main`, then repo Settings > Pages > Source: "GitHub Actions".

Landmark photos for the swipe reveal: drop `cube.jpg`, `park.jpg`, `union.jpg`, `ice.jpg` in `public/landmarks/`.
Edit places and tuning numbers in `src/data.js`.
